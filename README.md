# Expense-Tracker (Трекер расходов)

**Автор:** Гасанян Михаил  
**Дата:** май 2026

## Описание программы

Expense Tracker — это GUI‑приложение для отслеживания личных расходов. Программа позволяет:
* добавлять записи о расходах с указанием суммы, категории и даты;
* фильтровать данные по категории и диапазону дат;
* подсчитывать общую сумму расходов за выбранный период;
* просматривать все расходы в удобной таблице;
* сохранять данные в JSON‑файл.

## Функциональность

* Добавление расходов с указанием суммы, категории и даты.
* Просмотр всех расходов в удобной таблице.
* Подсчёт общей суммы расходов.
* Фильтрация по категории.
* Фильтрация по диапазону дат.
* Валидация вводимых данных (проверка корректности суммы и формата даты).
* Сохранение данных в JSON‑файл для последующего использования.

## Как использовать

### Запуск приложения

1. Убедитесь, что у вас установлен **Python 3.6 или выше**.
2. Скачайте файл `main.py` из репозитория.
3. Запустите приложение командой:
   ```bash
   python main.py
   
## Добавление расхода

1. Введите сумму в поле **«Сумма»**.
2. Выберите категорию из выпадающего списка.
3. Введите дату в формате **ДД.ММ.ГГГГ** (например, 12.12.2025).
4. Нажмите кнопку **«Добавить расход»** — запись появится в таблице.

## Фильтрация данных

* **По категории:** выберите нужную категорию из выпадающего списка в блоке **«Фильтры»**, затем нажмите **«Применить»**.
* **По дате:** введите начальную и/или конечную дату в соответствующих полях, затем нажмите **«Применить»**.
* **Сброс фильтров:** нажмите кнопку **«Сбросить»**, чтобы отобразить все записи без фильтрации.

## Пример использования

### Пример 1: Добавление расходов

Добавьте несколько записей:

1. **Сумма:** 444  
   **Категория:** коммунальные платежи  
   **Дата:** 12.12.2025

2. **Сумма:** 37  
   **Категория:** транспорт  
   **Дата:** 20.04.2026

3. **Сумма:** 10000  
   **Категория:** развлечения  
   **Дата:** 01.05.2026

После добавления все записи отобразятся под таблицей.

### Пример 2: Фильтрация

#### Фильтрация по категории

1. Выберите категорию **«транспорт»** в фильтре.
2. Нажмите **«Применить»**.
3. В таблице отобразятся только расходы с категорией **«транспорт»**.

#### Фильтрация по дате

1. Введите в поле **«с»**: 12.12.2025.
2. Введите в поле **«по»**: 05.05.2026.
3. Нажмите **«Применить»**.
4. В таблице отобразятся расходы за период с 12 декабря 2025 по 05 мая 2026 года.

* **Язык программирования:** Python 3.6+.
